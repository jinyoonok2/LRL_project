# Slide History

This folder preserves dated, copy-ready slide content for project updates.

## Naming Convention

Use:

```text
YYYY-MM-DD_topic.md
```

Create a new file for each significant update instead of overwriting an older deck. This keeps the progression of experiments, results, decisions, and next steps available as project history.
